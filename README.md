# AI Phishing Detection System

An AI-based cybersecurity system that uses machine learning to identify potentially malicious phishing URLs and distinguish them from legitimate URLs.
## Author

**Suliman Abdulaziz**
## Overview

Phishing attacks use deceptive URLs and websites to trick users into revealing sensitive information. This project applies machine learning techniques to URL classification to help detect potential phishing threats.

## Objectives

- Detect potentially malicious phishing URLs.
- Preprocess and analyze URL datasets.
- Extract relevant features for classification.
- Train and evaluate machine learning models.
- Compare model performance using standard evaluation metrics.

## Machine Learning Models

- **Random Forest**
- **Logistic Regression**
- **Convolutional Neural Network (CNN)**

## Methodology

1. **Data Collection:** Use phishing and legitimate URL datasets.
2. **Data Preprocessing:** Clean and prepare the dataset for model training.
3. **Feature Extraction:** Transform URL-related information into features suitable for classification.
4. **Model Training:** Train the selected machine learning models.
5. **Model Evaluation:** Evaluate performance using standard classification metrics.
6. **Phishing Detection:** Classify URLs as potentially phishing or legitimate.

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-score
